One-time setup

The browser can't read files from disk directly. To load your parquet files, you need a tiny local server. 30 seconds:
  1. Open PowerShell or Command Prompt
  2. Run: cd "C:\Users\chris\OneDrive\Documents\trackmanpitchingreports\data\by_date"
  3. Run: python -m http.server 8000
  4. Open: http://localhost:8000/battleship_app.html in your browser
Or, just drag and drop all the parquet files onto this page.
